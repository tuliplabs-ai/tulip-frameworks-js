# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in `tulip-frameworks-js`,
please report it through coordinated disclosure.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, use [GitHub private vulnerability reporting](https://github.com/tuliplabs-ai/tulip-frameworks-js/security/advisories/new)
on this repository, including:

- A description of the vulnerability
- Steps to reproduce the issue
- Any potential impact
- Any suggested fixes (if applicable)

We will acknowledge receipt of your report and send you regular updates about
our progress. Issues in the core SDK should be reported against
[`sdk-python`](https://github.com/tuliplabs-ai/sdk-python/security/advisories/new).

## Supported Versions

The latest released version receives security fixes.
